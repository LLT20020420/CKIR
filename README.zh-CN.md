# CKIR发布候选版

作者：Lingtao Lu（卢令韬）。版本：1.1.0rc1。自主代码采用MIT许可；第三方代码保留各自的许可。

本版解决了旧源码包的三个使用问题：

1. 增加包内的输入准备、三阶段训练和推理入口，运行代码不再依赖原机器的D盘目录或包外runner。
2. 文字阶段α=2.44、最终两阶段α=2.51由配置明确给出，评分函数不再隐藏早期默认力度。
3. 补齐原生GDA估计和95/5分数融合，分别输出纯CKIR、GDA和组合结果。

先运行`python inspect_package.py`检查文件，再运行`python run.py demo --device cpu --output "D:/ckir-work/demo"`查看一个完整小样例。输出目录须为新目录。真实数据的准备、训练与推理命令见英文README，可直接在PowerShell使用。

`data/episodes.json`记录了37类顺序、592个查询ID、22份支持抽样和88份干净/错标条件。`prepare`根据这些记录从显式指定的三个已有资产中组装输入，不重新抽样，不需要查询真值。特征和文字资产的文件名、大小及校验值见ASSETS.md和索引文件；代码ZIP不重复收录它们。

旧版固定源码及其ZIP原样保存在archive中。不要把archive中的历史驱动当作新版运行入口；新版统一运行`run.py`或`python -m ckir_gda`。

本版已通过合成小样例全流程检查；在同一合成输入上，新版头训练与联合训练的7步更新与冻结历史函数逐参数一致，GDA分数与原函数一致。另用一份原有检查点核对了592个已有查询，三种方法的判断均与原记录相同。详细检查范围见VALIDATION.md，没有因此生成或替换论文准确率。

本轮交付为本地发布候选版，尚无公开仓库地址或DOI。取得固定版本地址后，再同步论文B.4与代码可用性说明。
